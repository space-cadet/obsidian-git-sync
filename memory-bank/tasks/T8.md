## Details

Build the small set of dialogs and notices needed to explain active operations and failures.

## Subtasks

- [x] T8a: Progress display and retained result state
- [ ] T8b: Cancel action
- [x] T8c: Destructive-action confirmation for git rm
- [x] T8d: Error display and Git-style result summaries

## Acceptance Criteria

- [x] Active operations show only real progress information.
- [ ] Supported operations can be cancelled.
- [x] Failures are clear and actionable; destructive git-rm confirmation is available.

## KISS Boundary

Never invent phases or transfer metrics. This component explains operations but
does not own their workflow state.
